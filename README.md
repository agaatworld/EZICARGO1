# EZICARGO 1 — Trade Lite

The earlier version of the EZICARGO customer app (before the v2 rebuild).
EZICARGO is the trade OS between Chinese factories and traders in Malaysia, Singapore, Brunei and the Gulf:
EZI Ship (Guangzhou warehouse), verified factory shop, EZI Wallet with escrow and supplier payments, Group Buy and EZI Credit.

- Plain HTML, CSS and JavaScript, with no build step.
- Languages: English, Bahasa Melayu, 中文 and العربية (right to left).
- Themes: Light, Mist and Dark.
- Demo data only. Payments are in test mode until a licensed payment partner is connected. The test PIN is `246810`.

## Run

```
python3 -m http.server 8080
```
Then open http://localhost:8080. To publish it, you can also enable GitHub Pages on the `main` branch.
